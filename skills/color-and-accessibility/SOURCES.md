# Sources: color-and-accessibility

Format of every entry: title and URL, `Licence:`, `Use:` (`adapted` = text
paraphrased and restructured under the licence's terms; `cited` = idea or
finding only, no text taken).

- **Office for National Statistics, Service Manual, "Using colours in charts"** <https://service-manual.ons.gov.uk/data-visualisation/colours/using-colours-in-charts>
  - Licence: OGL-UK-3.0
  - Use: adapted — five or fewer colours; one colour per category, consistent across charts; grey for less important categories and one highlight; colour scales for ordered and diverging categories; sufficient contrast. Paraphrased; no palette values copied.
- **UK Government Analysis Function, "Data visualisation: charts"** <https://analysisfunction.civilservice.gov.uk/policy-store/data-visualisation-charts/>
  - Licence: OGL-UK-3.0
  - Use: adapted — do not rely on colour alone; text alternatives as a data table and/or a description of the key message, not repeating the title or every point; description under the chart; specific source link and data download. Paraphrased; no images used.
- **Anthropic, knowledge-work-plugins `data/skills/data-visualization`** <https://github.com/anthropics/knowledge-work-plugins/tree/main/data/skills/data-visualization> (commit e6b5053)
  - Licence: Apache-2.0
  - Use: adapted — accessibility checklist items (works without colour, alt text with the finding, data table alternative, grayscale printing). Rewritten; modified work. Apache-2.0 text in `../LICENSES/Apache-2.0.txt`.
- **K-Dense, `scientific-visualization` skill** <https://github.com/K-Dense-AI/scientific-agent-skills/tree/main/skills/scientific-visualization> (commit a1043ef)
  - Licence: MIT
  - Use: adapted — WCAG 2.2 contrast figures (4.5:1 text, 3:1 large text and essential graphics); grayscale screen is not a complete test. Paraphrased.
- **W3C, Web Content Accessibility Guidelines (WCAG) 2.2** <https://www.w3.org/TR/WCAG22/>
  - Licence: W3C Document License
  - Use: cited — success criteria 1.4.1, 1.4.3, 1.4.11 and 1.1.1. No text copied.
- **M. Okabe and K. Ito, "Color Universal Design (CUD): How to make figures and presentations that are friendly to colorblind people" (2002)** <https://jfly.uni-koeln.de/color/>
  - Licence: Copyrighted (web page)
  - Use: cited — the palette is named; no values or text reproduced.
